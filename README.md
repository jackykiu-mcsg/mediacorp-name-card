# Mediacorp Digital Name Card

This project is a digital name card web app for Jacky Kiu at Mediacorp, designed to provide a modern, interactive, and multilingual business card experience. The site features a visually engaging card flip animation, responsive layout, and support for multiple languages (Traditional Chinese, Simplified Chinese, Japanese, and English). 

Key features include:
- **Card Flip Animation:** Users can flip the card to view a QR code for easy sharing.
- **Multilingual Support:** Instantly switch between languages using the dropdown menu.
- **Contact Actions:** Quick access buttons for calling, emailing, and downloading the vCard.
- **Branding:** Prominent display of Mediacorp and associated brand logos.
- **Awards & Social Links:** Showcases recent awards and provides links to social media profiles.
- **Progressive Web App:** Includes manifest and icons for installation on mobile devices.

The design leverages Bootstrap 5 for layout, GSAP for animations, and custom CSS for a polished, professional appearance. All assets and code are optimized for fast loading and mobile-first
